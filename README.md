##📚 StudyFlow

Plan smarter. Study better. 🎯

StudyFlow is a mobile study companion designed to help students organize their subjects, review lessons, complete quizzes, and track their academic progress in one convenient application.

🌟 Overview

StudyFlow combines useful study tools in one mobile app. Students can manage their subjects, create notes and flashcards, answer quizzes, use a Pomodoro timer, and monitor their learning progress.

This project was created as a portfolio application to demonstrate mobile app development, user interface design, data management, and membership-based features.

✨ Features
👤 User registration and login
🏠 Student dashboard
📚 Subject and topic management
📝 Digital notes
🧠 Custom flashcards
❓ Multiple-choice quizzes
📊 Quiz scores and answer reviews
⏱️ Pomodoro focus timer
🔥 Study streak tracking
📅 Exam countdown
📈 Progress tracking
💎 Free and Pro membership options
🌙 Dark mode
🎨 Student-friendly interface

🆓 Free Features

Users on the Free Plan can access:
📚 Up to three subjects
📝 Basic note-taking
🧠 Flashcard creation
❓ Limited daily quizzes
⏱️ Pomodoro timer
📊 Basic progress tracking
🔥 Study streaks

💎 Pro Features

Users on the Pro Plan can access:
♾️ Unlimited subjects
📝 Unlimited notes and flashcards
❓ Unlimited quizzes
📈 Advanced progress analytics
🗓️ Personalized study plans
☁️ Cloud backup
📄 PDF note export
🌙 Dark mode
🚫 Ad-free experience
⏰ Exam countdown widgets

🚀 Installation and Setup

✅ Requirements

Before running or editing the project, make sure you have:
🐙 A GitHub account
🛠️ Access to the visual development platform used for this project
🌐 A browser or development environment
🔥 A Firebase account if authentication and cloud storage are enabled

📥 Clone the Repository

git clone https://github.com/your-username/studyflow.git

Move into the project folder:

cd studyflow

Replace your-username with your GitHub username.

▶️ Run the Project
Open the project in the selected visual development platform.
Configure the database and authentication settings.
Add the required environment variables.
Run the application in preview mode or on an emulator.
Create a test account.
Explore the available features. 🎉
